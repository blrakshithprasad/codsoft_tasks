# CODSOFT Backend Task 2 — Contact Management System

## Implemented
- Flask REST API
- Relational contacts database
- Name, email, phone, address and company
- Add/update/delete/retrieve
- Search by name/email/phone
- Sorting and pagination
- Validation
- Duplicate prevention
- Meaningful errors/status codes
- Scalable app/models/routes/utils structure
- OpenAPI summary
- Pytest coverage

Run:
```bash
pip install -r requirements.txt
python run.py
```

Test:
```bash
pytest -q
```
